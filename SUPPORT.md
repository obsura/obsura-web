# Support

## Getting Help

For usage questions and contribution guidance:
- Open a GitHub issue with clear reproduction details and environment info.

For security-related concerns:
- Follow SECURITY.md and report privately.

## Recommended Issue Content

Include:
- What you expected to happen.
- What happened instead.
- Steps to reproduce.
- Browser, OS, and app version/commit.
- Logs or screenshots when relevant.

## Response Expectations

This project is maintained on a best-effort basis.
Maintainers prioritize security, production regressions, and release blockers.
