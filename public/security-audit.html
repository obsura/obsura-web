Security Audit

Obsura follows practical security controls to protect users and service integrity.

Controls

  • HTTP hardening headers and secure deployment defaults.
  • Rate limiting and abuse protection at the edge layer.
  • Dependency updates and release pipeline safeguards.

Disclosure Process

Vulnerabilities should be reported privately. Do not post sensitive findings in public issues.

Responsible Reporting

Send security reports to security@obsura.one with clear reproduction details and impact assessment.
