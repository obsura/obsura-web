# Security Policy

## Supported Versions

Security fixes are prioritized for the latest release line on main.

| Version | Supported |
| ------- | --------- |
| Latest main | Yes |
| Older branches | Best effort |

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Report security issues privately to:
- Email: security@obsura.dev

Include the following details:
- Affected component and version/commit.
- Reproduction steps and expected impact.
- Proof-of-concept details, logs, or screenshots as needed.
- Suggested mitigation if available.

## Response Targets

- Initial acknowledgment: within 72 hours.
- Triage decision: within 7 business days.
- Status updates: provided regularly until resolution.

## Disclosure Process

- We validate and triage the report.
- We develop and test a fix.
- We coordinate a release and publish advisory notes when appropriate.
- We credit reporters who request attribution.
